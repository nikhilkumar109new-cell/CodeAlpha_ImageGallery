# CodeAlpha Image Gallery

A responsive photo gallery built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive photo grid
- Category filters for Nature, Architecture, and Travel
- Full-screen lightbox with next/previous navigation
- Keyboard navigation with arrow keys and Escape
- Hover effects, subtle transitions, and lazy-loaded thumbnails
- Accessible button labels and focus states

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. An internet connection is needed to load the hosted Unsplash photos and Google Fonts.

## Files
- `index.html` — page structure and lightbox
- `style.css` — visual styling and responsive layout
- `script.js` — gallery data, category filtering, and image navigation
